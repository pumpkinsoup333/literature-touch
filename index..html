不用补偿过去，只顺手看一下时间去了哪里。原因可以只点一个，也可以什么都不记。

绿色＝这个小时至少进入过 1 次，格子里会显示 ×1、×2、×3…；蓝灰＝当前小时仍在进行且尚未进入；米色＝已经结束但没进入；灰色＝提前排除；虚线＝未来。

提前排除一个大块项目

只允许排除当前或未来的小时，不把已经过去的 missed 事后改掉。固定午休和傍晚休息本来就不在统计里。

接续线索写一句给下一时段的自己

不是待办。只留一句：我刚才想到哪了？ 它只是把上一段思考的 context 递给下一时段。

按 UTC+8 计时。12:00–14:00、17:00–19:00、23:00 后默认休息，不进入分母。

设置后首页会出现“打开文献并记一次”。每次重新进入文献都可以点一次；网页记录次数，但不监控具体读了多久。

数据只保存在当前 Safari / 主屏幕网页的本地存储中。更新 GitHub 上的网页不会自动清掉记录，但清除网站数据或换网址可能会。
